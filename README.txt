CeQur Simplicity Tracker — iPhone Home Screen web app

HOW TO INSTALL (GitHub Pages, free HTTPS hosting)
1. On a computer, sign in to github.com and create a PUBLIC repository named cequr-tracker. Note: the app code is public, but your dose data is stored locally on your phone and is not uploaded to GitHub.
2. Upload the FOUR files from this folder (index.html, manifest.webmanifest, icon.svg, sw.js) to the repository root. Do not upload private dose backups.
3. Open repository Settings > Pages. Choose Deploy from a branch, main, / (root), then Save.
4. After Pages publishes, open https://YOUR-USERNAME.github.io/cequr-tracker/ in Safari on your iPhone.
5. Tap Safari's Share icon > Add to Home Screen > Add. Open the new CeQur icon.
6. The initial 168-unit count and 18-unit daily baseline are estimates from the November 3, 2026 conversation. Verify the remaining units and use Adjust balance if needed before logging new clicks. The 18-unit daily baseline is not an itemized record.
7. Each tap on the large -2 button records a manual 2-unit dose and subtracts from remaining. Undo only reverses the immediately preceding tap. New patch archives the old patch. Export backup regularly using Files or iCloud Drive; Import backup restores it.

IMPORTANT LIMITATIONS
- Browser localStorage is per-device/per-website. Data does not sync with ChatGPT, other phones, or medical records.
- Clearing Safari website data or changing the hosted URL may erase or hide the tracker data. Export backups regularly.
- This is a manual inventory log, NOT a medical device or insulin dose calculator. It does not deliver insulin or verify delivery. Do not use it to decide insulin doses.
- Initial values are estimated. Verify against your own records.
